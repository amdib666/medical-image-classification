# 🫁 Pneumonia Detection AI (Demo)

This project is a simple AI-powered web application that allows users to upload chest X-ray images and receive a prediction.

## 🚀 Features

* Upload any image
* AI-based prediction
* Simple web interface using Gradio
* Works on desktop and mobile

## 🛠️ Technologies

* Python
* TensorFlow / Keras
* Gradio
* NumPy / PIL

## ⚠️ Disclaimer

This project is for educational purposes only and is not intended for medical use.

## ▶️ How to Run

```bash
pip install -r requirements.txt
python app_gradio.py
```
